# Первый промт для нового проекта

Вставьте это сообщение в первый чат нового Codex-проекта:

> Подготовь FaLoudit (Fallout Localization Auditor) к работе по инструкции проекта. Сам проверь наличие утилиты, конфигурацию, языки исходника и перевода, активный профиль, doctor и индекс. Если sourceLanguage/targetLanguage или другие действительно необходимые данные не указаны — спроси только их. Когда всё будет готово, сообщи языковую пару и выбранный профиль, затем напиши, что готов принимать проблемные строки для поиска и анализа.

После сообщения о готовности присылайте строки обычным текстом, например:

> Advanced Targeting Sensor

или:

> В диалоге старейшины вместо русского текста показывается: Now, who can tell me the primary components of gunpowder?

Codex должен самостоятельно выполнить поиск, `explain`/`trace`, определить победивший plugin и MO2-мод и вернуть конечный диагноз.
