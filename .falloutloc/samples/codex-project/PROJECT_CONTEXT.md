# Локальный контекст FaLoudit

Заполните значения, если хотите заранее привязать проект к конкретной сборке.
Пустые значения означают, что Codex должен запросить недостающие данные при
первом запуске.

```text
MO2/build root:
Active profile:
Game mode:
```

Codex должен проверить значения через `discover` и `doctor`, а не считать их безусловно актуальными.

Если корневой путь не указан или недоступен, Codex должен спросить путь к
сборке. Название профиля нужно спрашивать только при реальной неоднозначности.
Не подбирать другой профиль молча.
