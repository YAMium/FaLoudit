# Codex-проект для FaLoudit

FaLoudit — сокращение от **Fallout Localization Auditor**.

## Подготовка нового проекта

1. Создайте пустую папку нового Codex-проекта.
2. Скопируйте `AGENTS.md` из этого шаблона в корень новой папки без переименования.
3. Создайте `tools/faloudit`.
4. Распакуйте туда `faloudit.exe` и `e_sqlite3.dll` из актуального Windows-архива FaLoudit.
5. Откройте корневую папку как проект в Codex.
6. Отправьте текст из `FIRST_PROMPT.md`.

Ожидаемая структура:

```text
My Fallout Translation Project/
  AGENTS.md
  FIRST_PROMPT.md
  PROJECT_CONTEXT.md
  tools/
    faloudit/
      faloudit.exe
      e_sqlite3.dll
  LICENSE.txt
  THIRD-PARTY-NOTICES.md
  SOURCE.md
```

Готовый архив содержит пустой универсальный `PROJECT_CONTEXT.md`. При желании
заполните его до первого запуска; иначе Codex запросит только корень сборки и,
языки исходника/перевода и, если discovery найдёт несколько вариантов, точное
имя активного профиля.

Если шаблон используется на другом компьютере или для другой сборки, Codex попросит новый путь к корню MO2, например:

```text
C:\Modding\My TTW Instance
```

Название профиля он должен спросить только при реальной неоднозначности. Конфигурация и индекс будут записаны исключительно в `<project>/.falloutloc`.

После первичной индексации достаточно отправлять проблемные строки в тот же чат. Если сборка или активный профиль были изменены, сообщите об этом перед следующей строкой — Codex проверит свежесть и обновит индекс инкрементально.

## Готовая утилита

Архив приложения в исходном проекте:

```text
.falloutloc/cache/packages/faloudit-<version>-win-x64.zip
```

Файлы `faloudit.exe` и `e_sqlite3.dll` должны находиться рядом.
